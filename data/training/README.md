# 冻结训练索引

[cohort.json](cohort.json) 配套 A169/B12/C6/S2，仅保留训练所需的 158 名 OASIS-1 研究受试者。

- `subjects`：研究标识、会话、相对 MRI/FSL_SEG 路径、CDR 监督标签及三分类标签。
- `groups.a_fit`：A 的有序 78 人拟合集。
- `groups.bc_refit`：B/C 的有序 158 人重训集。
- `groups.s_refit`：同一 158 人中有序的 80 名真实阳性者。

列表顺序是固定种子打乱前的输入顺序，复现时不要排序或替换成员。
标签 `0/1/2` 分别对应 CDR 0、0.5、1 或 2；A/B/C 使用是否阳性的二分类标签，S 使用阳性者的程度标签。
CDR 只作训练监督，不作为模型输入特征。

本目录不含原始图像、评价集、实验预测或训练日志。数据准备和训练命令见 [模型说明](../../src/model/README.md)。
