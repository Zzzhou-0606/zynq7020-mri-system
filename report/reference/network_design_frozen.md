# 两级 MRI 分类网络设计冻结说明

> 状态：用户已确认冻结网络设计。  
> 冻结日期：2026-10-22。  
> 版本：设计 v1。  
> 范围：一级三方向加权分类、二级双方向特征拼接分级、两级连接与评分展示语义。  

## 1. 冻结结论

系统采用层级分类（Hierarchical Classification）：

1. **一级 D：**轴位四层 CNN、冠状位冻结 ResNet-18、矢状位冻结 ResNet-18分别输出有痴呆分数，按 **42.7%／30.0%／27.3%** 加权。
2. **二级 S：**仅在一级阳性时执行，将冠状位512维特征与矢状位512维特征按固定顺序拼接，再由 **1024→2 单层全连接头**输出极轻／轻度及以上分数。
3. **连接：**一级的判定控制是否调用二级；二级输入图像特征，不以一级的单个分数作为输入。
4. **展示：**主提示分为 **100×一级阳性分数**，并列显示三分类参考和复核提示；不把一级与二级分数再次平均。
5. **阈值：**一级、二级均为 **0.5**，相等时归入正类。50分是一级0.5阈值的显示换算。

冻结模型用于本交付的两级分类流程；开发组指标不代表独立或临床验证结果。

## 2. 整体数据流

```text
同一份符合输入契约的 MRI 体积与脑掩膜
                       │
       ┌───────────────┼────────────────┐
       ↓               ↓                ↓
   轴位34片         冠状位38片       矢状位59片
       ↓               ↓                ↓
   四层CNN        冻结ResNet-18     冻结ResNet-18
       ↓               ↓                ↓
   轴位分数pA     切片特征取平均     切片特征取平均
                       ↓                ↓
                 原始特征fB[512]   原始特征fC[512]
                    │     │          │     │
            一级B分类头   │    一级C分类头  │
                    ↓     │          ↓     │
                   pB     │         pC     │
                    │     │          │     │
    pA、pB、pC ─────┴─────┼──────────┘     │
            ↓             │                │
 pD=0.427pA+0.300pB+0.273pC│                │
            ↓             │                │
      一级阈值0.5         │                │
       /          \       │                │
    pD<0.5      pD>=0.5    │                │
      ↓             ↓     │                │
 无痴呆倾向     调用二级S ←┴────────────────┘
                输入[fB,fC]共1024维
                       ↓
                 二级自身标准化
                       ↓
                  全连接1024→2
                       ↓
                Softmax得到pS
                  /          \
              pS<0.5      pS>=0.5
                 ↓             ↓
              极轻倾向    轻度及以上倾向

所有成功结果：主提示分=100×pD，配合最终类别与提示文本显示。
```

冠状位与矢状位使用相同的冻结ResNet-18编码器权重，但分别处理各自切片。软件实现可以复用同一编码器实例；这不表示两个方向图像只需计算一次。一级执行时应保留两方向原始平均特征，供二级复用，避免对相同切片重复提取特征。

## 3. 输入和预处理契约

现有一级联合推理接口接收的是**已对齐到既有T88空间的体积**，不是任意扫描仪原始文件直接输入：

- MRI与脑掩膜形状均为`176×208×176`，体素1毫米，保持现有磁盘网格方向。
- MRI为现有流程期望的原强度数据，掩膜必须有限、二值且非空。
- 不在当前`predict_volume`内部执行配准。未来完整入口必须先满足此契约，再调用网络。
- 三方向切片输出均为`128×128`；沿用已有选片、裁剪、方向、掩膜和归一化实现，不因预测类别改变预处理。

| 分支 | 切片与范围 | 固定强度编码尺度 | 后续处理 |
|---|---|---:|---|
| A：轴位 | 磁盘轴位索引47–80，共34片 | 0.125 | 现有四层CNN |
| B：冠状位 | 索引78–115，共38片；既有局部裁剪 | 0.25 | 现有ImageNet输入转换＋冻结ResNet-18 |
| C：矢状位 | 索引49–78及94–122，共59片 | 0.25 | 现有ImageNet输入转换＋冻结ResNet-18 |

范围均为既有代码中的零基磁盘索引。冠状位裁剪使用既有中心`[85.5,69.5]`和104毫米视野；矢状位沿用208毫米视野及现有方向变换。固定图谱定位不是逐人病变或海马分割。

配置与实现位于 `src/model/training/configs/frozen_training.json`、`src/model/training/trainers/frozen.py` 和 `src/model/training/reference/frozen_hierarchy.py`（相对交付根目录）。

输入不兼容、编码失败或推理失败不能回填为0分或“无痴呆”。沿用失败状态并说明无法评价；输入兼容方案的变更应单独记录，不能静默修改本次固定预处理。

## 4. 一级 D：三方向加权

三路输出都取其二分类Softmax的正类分数：

```text
pA = 轴位模型的有痴呆分数
pB = 冠状位模型的有痴呆分数
pC = 矢状位模型的有痴呆分数

pD = 0.427*pA + 0.300*pB + 0.273*pC
```

| 模块 | 冻结结构 | 当前参考检查点 |
|---|---|---|
| A | 轴位34片、现有四层CNN及会话汇总 | A第169轮 |
| B | 冠状位38片、冻结ResNet-18、平均512维特征、一级自身标准化及512→2头 | B第12轮 |
| C | 矢状位59片、冻结ResNet-18、平均512维特征、一级自身标准化及512→2头 | C第6轮 |

融合权重固定为 42.7%／30.0%／27.3%，由 `src/shared/model_contract/system_frozen_20261022.json` 记录。

## 5. 二级 S：共享特征与单层分类头

取编码器输出经切片平均、**尚未经过一级B/C分类头标准化**的特征：

```text
fB = mean(38张冠状位切片的ResNet特征)    # 512维
fC = mean(59张矢状位切片的ResNet特征)    # 512维
fS = concatenate([fB, fC])               # 1024维，顺序固定
zS = (fS - meanS) / stdS
logitsS = WS*zS + bS                     # 输出2维
pS = softmax(logitsS)[1]
```

- `meanS`和`stdS`从二级选定检查点加载；它们是二级训练侧的统计量。
- 不能拿一级B/C已标准化特征代替`fB/fC`，也不能在推理时用当前患者或评价组重新估计二级标准化统计量。
- 当前二级训练使用总体标准差（`unbiased=False`），并将标准差下限设为`1e-6`；推理直接复用保存值。
- 输出顺序固定为`[极轻, 轻度及以上]`，`pS`为第二项分数。
- 新增头只有**1层全连接，没有隐藏层**，参数为`1024×2+2=2050`。
- 2,050只代表新增二级头参数，不能代表完整网络、总算量或FPGA资源。

这里的连接是**特征拼接**，不是两个方向二级分数的加权，也不是把一级`pD`送入一个新分类器。均值池化、标准化、拼接和Softmax不计入通常所说的可训练层数。

二级训练与推理实现见 `src/model/training/trainers/frozen.py` 和 `src/model/training/reference/frozen_hierarchy.py`。

## 6. 两级路由与最终类别

| 一级条件 | 二级条件 | 最终类别编号 | 分类参考文本 |
|---|---|---:|---|
| `pD<0.5` | 不调用二级头 | 0 | 无痴呆倾向 |
| `pD>=0.5` | `pS<0.5` | 1 | 极轻倾向 |
| `pD>=0.5` | `pS>=0.5` | 2 | 轻度及以上倾向 |

未执行二级时，二级分数在逻辑上为“不适用”，不能填写0来冒充已预测极轻。一级成功但二级失败时，可保留一级分数与阳性判断，程度标为“未完成”；不能自动补成某个严重程度类别。

通信字段及异常状态见 [通信协议](protocol.md)。

训练标签依据当前临床痴呆评定（Clinical Dementia Rating, CDR）：0对应无痴呆组，0.5对应极轻，当前合法值1和2合并为轻度及以上。CDR只用于监督标签，不能作为MRI-only模型输入。二级只训练同一全局训练分区中的真实阳性者，不按一级预测筛人。

## 7. 评分与显示规则

```text
模型提示分 = 100*pD
```

| 项目 | 冻结含义 |
|---|---|
| 分数范围 | 0–100，反映一级的阳性倾向 |
| 暂定提示线 | 50，等价于一级阈值0.5 |
| 程度参考 | 来自两级路由的类别，不把pS混入主分数 |
| 分数解释 | 模型提示分，不是已经校准的患病概率，也不是病情严重程度量表 |
| 低分解释 | 模型未达到阳性提示阈值，不等于排除痴呆或无需关注症状 |
| 显示与判定 | 使用未舍入的pD/pS执行阈值判断；显示精度不能改变类别，接近阈值的结果应避免因舍入造成提示矛盾 |

展示示例，**仅为假设数值，不是真实患者结果**：

```text
假设 pD=0.72，pS=0.65：

模型提示分：72 / 100
分类参考：轻度及以上倾向
提示：模型达到复核阈值，请结合临床信息评估。
```

50分作为当前研究原型的提示规则，不宣称是已经验证的医学干预或就诊界限。0分也不能表述成“确定没有痴呆”。

## 9. 开发阶段结果与解释

同一开发组结果：一级 35/40=87.5%；二级在 20 名真实阳性上 13/20=65%、平衡准确率 75%、AUC 0.75；两级串联三分类 29/40=72.5%。三项分母与任务不同，不能互相替代。

二级将 14 名极轻者中的 7 人判重。开发组参与过样本调整、融合权重选择及实验比较，因此这些成绩不作为独立测试结论。工程实现与当前性能见 [性能说明](../current_performance.md)。

## 10. 版本一致性

更换检查点、预处理、融合权重、特征拼接顺序、阈值或评分公式时，应更新模型版本和契约。数值精度或计算方式变化需要比较分数与分类一致性，尤其是阈值附近样本。
