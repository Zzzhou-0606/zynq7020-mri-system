# 当前OVERLAP版本性能

125MHz，overlap-v1，INT16，batch4；A34/B38/C59共131张、34次硬件调用。
既有正式接口一次同病例板测：

| 时间边界 | 秒 |
|---|---:|
| C++完整分类程序 | 19.89259341 |
| A/B/C引擎累计 | 17.742254187 |
| A引擎34张 | 0.318242957 |
| B引擎38张 | 6.829536734 |
| C引擎59张 | 10.594474496 |
| 主机创建任务到观察完成 | 22.8657557 |
| 服务内部提交至结果 | 22.124477613 |

时间区间互有包含，不能相加；网络计时不包含PC原始MRI生成切片和板端启动。
与保存记录的分类字段一致属于回归证据，不是新增准确率或临床有效性证据。
当前125MHz建立/保持裕量+0.131/+0.012ns；150MHz实现未满足建立时序，因此发布125MHz。
原测量发生于正式SD部署并重启后；目录整理本身不代表重新上板验收。
