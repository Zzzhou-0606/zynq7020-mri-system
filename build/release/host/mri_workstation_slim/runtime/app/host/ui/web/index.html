删除这次扫描？
将同步删除该扫描在原开发板上的任务、影像和患者访问，再从本地病例库移除。开发板离线或删除未确认时保留本地记录；同病例其他扫描不受影响。两端均无该病例记录时回收编号。本地文件保留，不再直接恢复已同步删除的旧任务。

  
开发板配对
在开发板触屏生成临时配对码，5 分钟内输入，成功后立即失效。软件自动加密保存长密钥，之后无需重复输入。

  
患者访问
板端分析完成后会自动生成访问码并发布。患者使用病例编号和独立访问码查看本次结果。再次发布会更新同一开发板上此病例的访问码，旧码失效；其他已发布任务共用新码。
确认撤销本次任务的患者访问？撤销后，患者无法查看本次任务；同病例其他已发布任务保留。
