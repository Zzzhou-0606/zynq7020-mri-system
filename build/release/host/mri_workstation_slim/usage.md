# MRI 工作台便携版

适用于 Windows 10/11 64 位。完整获取 `mri_workstation_slim` 软件文件夹后，双击 **mri_workstation.exe**。
Python、界面浏览器内核、运行依赖和本地模型已包含在包内，无需安装或配置 Python，也不需要单独下载模型。

## 文件夹

```text
mri_workstation_slim/
  mri_workstation.exe
  portable.json
  usage.md
  third_party_components.md
  runtime/                 程序、Python、依赖和 WebView2
  models/                  分类与分割模型
  data/
    cases/                 病例库、MRI 副本、任务和分割结果
    settings/              地址偏好和医生配对凭据
    logs/                  启动与运行日志
    exports/               默认报告导出位置
```

将整个文件夹放在具有写入权限的位置，例如 `D:\mri_workstation`。不要直接在 ZIP 中打开 EXE，也不要只复制 EXE。
病例和影像可能持续占用磁盘空间，建议放到空间充足的本地硬盘。保留完整文件夹结构。

## 首次使用

1. 双击 EXE。病例库初始为空，导入后自动编号从 **001** 开始；医生凭据在配对后保存。
2. 填入开发板实际地址，点击“检查连接”；配对时使用开发板显示的六位临时配对码。
3. 使用“导入 MRI 扫描”选择单病例文件夹或批量导入。导入后，在当前病例点击分析，或在批量队列选择需要分析的病例。
4. 设置中可选择 CPU 或 CUDA 分割。CUDA 运行库已包含；使用 NVIDIA GPU 仍需电脑安装兼容的显卡驱动。没有可用 NVIDIA GPU 时选择 CPU。
5. 工作台支持自动发布、访问码更新或撤销、复制访问地址、后台影像同步、停止任务、查看历史、切片浏览和报告导出。

开发板分析和患者访问仍需开发板服务可达。便携包不改变开发板的软件或网络配置。

## 保存、移动和更新

- 所有默认用户数据均保存在软件同目录的独立 `data` 文件夹，不写入 `models` 或依赖目录。
- 备份或移动前先停止任务并正常关闭软件，再复制整个软件文件夹；已保存的新分割结果使用可迁移路径。
- 同一 Windows 账户移动文件夹可继续读取已保存凭据。换电脑或 Windows 账户时，病例数据可以移动，医生端需要重新配对，因为密钥由 Windows 账户加密保存。
- 更新时先关闭程序并备份 `data`；将新版本解压到新文件夹，再复制旧版的整个 `data` 文件夹。不要用空 `data` 覆盖旧病例库。

## 故障定位

- 无法启动时先确认已完整解压、目录可写，查看 `data/logs` 中最新日志。
- Windows 若提示未知发布者：当前 EXE 未做商业代码签名，先确认文件来自本项目的发布包。
- CUDA 不可用时，在设置中选择 CPU；CPU 分割速度通常较慢。
- 便携版使用 Windows 的 .NET Framework 4.x 桌面组件。应在正常启用该组件的 Windows 10/11 x64 上运行。

运行验证覆盖便携环境、目录迁移、WebView2 交互、CPU 分类参考以及 CPU/CUDA 分割进程。全新 Windows 电脑的兼容性需在目标环境确认；合成体积的分割执行检查仅说明程序执行和输出读取正常，不作为分割精度或区域测量证据。
