# 板卡、网络与 Jupyter

## 通用流程

1. 按板卡完整型号和硬件版本选择PYNQ镜像，核对DDR、MIO和外设配置。
2. 烧卡前确认读卡器盘符、物理磁盘、容量、非系统盘身份，备份原文件。原始 IMG 写入会重建分区。
3. 板卡断电后插卡，设置 SD 启动；接 PS 网口至路由器，电脑处于同一局域网。USB_UART 接电脑用于启动诊断。
4. 启动后串口执行 `ip -4 addr` 查看网口 IPv4 地址。没有地址时检查网口、链路灯、DHCP 和启动日志。
5. 浏览器访问板端 Jupyter 服务地址。端口、用户名和密码以该镜像说明为准，不将一块板的默认值推广到所有镜像。
6. 在板端 Jupyter 新建 Python 3 Notebook，执行 `import pynq; print(pynq.__version__)` 和 `import platform; print(platform.machine())`，确认使用的是板端内核。
7. 上传技能包及适配的 bit/hwh；运行 `bringup.ipynb`。

电脑与板卡直连也可使用 Jupyter，但需配置同网段 IPv4；不能因为没有 Internet 就认为不能访问局域网 Jupyter。远程公开访问不在本技能范围内。

## 领航者 7020 配套配置

依据本地《领航者 ZYNQ 之 PYNQ 开发指南 V3.2》PDF 第 19、22–25 页：

- 镜像：`ZYNQ-7020-2.7.0.img`，厂商资料包提供，不能替换成 PYNQ-Z2 镜像。
- 串口：USB_UART，P5 接 PS 串口；115200、8 数据位、1 停止位、无校验、无流控。
- 网口：PS 千兆以太网口。路由器方式通过 DHCP 获取地址，用 `ip a s` 查看。
- 指南同时给出静态 `192.168.2.99` 和主机名地址 `http://pynq:9090`；优先依据实际 IP 和运行端口。当前板卡配置未验证前，不把该默认地址当作现状。
- 指南的该镜像初始串口账户为 `xilinx`，Jupyter 初始密码也见厂商指南。凭据由用户自行输入。
- 更换 PYNQ 镜像会改变板卡启动环境。备份应覆盖启动文件及需要保留的数据；文件复制与整盘恢复镜像的用途不同。

写卡和校验完成后 Windows 可能无法识别 Linux 分区；如果弹出格式化提示，取消。不要为使 Windows 识别而格式化新镜像分区。
