# 复用与验收清单

## 哪些变更需要重做哪些验证

| 变更 | 可保留 | 必须重新检查/测试 |
|---|---|---|
| 同位流换输入值 | 环境、接口和构建证据 | 数值参考、范围/溢出、代表样本 |
| 改 shape/dtype/长度 | 比较和报告工具 | 字节数、长度上限、打包、边界及短包 |
| 换计算 IP | 框架、提示词、排错方法 | 控制协议、寄存器、独立参考、新 bit/hwh、实板计算 |
| DMA 改 m_axi | 环境和数值比对 | 指针与内存契约、结束语义、停止/复位路径 |
| 换板或镜像 | 算法和数据契约中仍适用部分 | DDR/MIO、外设、位流/设备树、驱动版本、全部新板硬件检查 |
| 接入 Qt/服务 | 已验证算子输入输出 | 并发/所有权、进度与错误、显示和触摸、冷启动 |

## 单次接入验收

- [ ] 配置表已填写，所有未知项有明确处理；没有猜测的地址。
- [ ] 默认离线入口通过；输出明确区分 offline、board_dma、board_m_axi。
- [ ] 最小硬件输入通过，并保存真实输入生成规则和独立参考。
- [ ] 零值、代表随机值、数值边界和合法长度边界通过。
- [ ] 故意错误参考能被检出；超长/非法契约在启动前拒绝。
- [ ] 数据长度/内容匹配；没有只对正确前缀作比较。
- [ ] 超时路径明确：模拟验证和硬件验证分别记录。
- [ ] 重新加载、恢复和再次调用符合该设计；无未确认停止的缓冲区被释放。
- [ ] 从新目录按给出的步骤可复现，不依赖原作者绝对路径或历史内核变量。
- [ ] 明确未验范围；换板未实测时不写“跨板验证通过”。

故障测试按设计选择模拟注入或独占板端试验，并记录所用方法；待完成项列入后续验收计划。
